   https://www.dffh.vic.gov.au/publications/rental-report
2. ABS Wage Price Index, Table 2b, saved as `634502b.xlsx`
   https://www.abs.gov.au/statistics/economy/price-indexes-and-inflation/wage-price-index-australia/latest-release
3. ABS Census 2021 DataPack, General Community Profile, Local Government Areas, Victoria
   https://www.abs.gov.au/census/find-census-data/datapacks
   Save `2021Census_G02_VIC_LGA.csv` and the geography file (as `geog_desc.xlsx`) in `census/`
